# Eave

Eave puts websites in the macOS menu bar. Each site opens in its own panel and keeps its own cookies.

This repository only hosts release builds and the update feed. The source code is private.

## Install

1. Download the DMG from [the latest release](https://github.com/Snowyyyyyy1/eave-releases/releases/latest).
2. Open the DMG and drag Eave to Applications.
3. This build is not notarized by Apple yet, so macOS blocks it the first time. Open System Settings › Privacy & Security, scroll down to the message about Eave, and click Open Anyway. Then open Eave again.

Requires macOS 14 or later, on Apple silicon or Intel.

## Updates

Eave checks this repository once a day and offers new versions. You can turn this off in Settings › General.

## 安装

1. 从[最新版本](https://github.com/Snowyyyyyy1/eave-releases/releases/latest)下载 DMG。
2. 打开 DMG，把 Eave 拖进“应用程序”。
3. 这一版还没有经过 Apple 公证，第一次打开会被 macOS 拦下。打开“系统设置 › 隐私与安全性”，往下找到关于 Eave 的提示，点“仍要打开”，再打开一次 Eave。

需要 macOS 14 或更高版本，支持 Apple 芯片和 Intel 芯片。

## 更新

Eave 每天检查一次这个仓库，有新版本时会提示。可以在“设置 › 通用”里关掉。
